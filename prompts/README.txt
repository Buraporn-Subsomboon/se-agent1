Put your team's structured prompts here, one .md file each.

Each prompt must have these 8 headings, in the class template format:
  ## 1. Role   ## 2. Context   ## 3. Task/Objective   ## 4. Requirements
  ## 5. Constraints   ## 6. Process   ## 7. Output Format   ## 8. Verification

See docs/PROMPT_TEMPLATE.md for a fill-in version and docs/TEAM_PROJECT_GUIDE.md for how they fit
the project. The router picks agents by what their Role and Task say, so the file name is just a label.
An empty prompts/ folder is normal on a fresh fork: the router will tell you to add some.
