# se-agent

A small prompt router for the Software Engineering course (CSCE 5565). You write structured
prompts (one per Sommerville topic); a **Router** reads your project brief, picks which prompt-agent
runs next, passes earlier work forward, and saves everything to `output/<timestamp>/`.

> **Your prompts are not in this repo.** Creating them is part of the course. Add them to `prompts/`
> in your team's fork.

## What you need
- Python 3.12 and [uv](https://docs.astral.sh/uv/) (or pip)
- An OpenAI API key **only if your instructor has told you to run it yourself.**
  In class projects the instructor runs it for the team (see `docs/TEAM_PROJECT_GUIDE.md`, "Runs and cost").

## Setup (once)
```
git clone <your team's fork URL>
cd se-agent
uv sync
copy .env.example .env      (Mac/Linux: cp .env.example .env)
```
Open `.env`, paste your key. **Never commit `.env`.**

## Check everything works (no key spent)
```
uv run pytest
```
You should see all tests pass. They use a fake model, so this costs nothing.

## Estimate before you spend
```
uv run python cost_estimate.py
```
Shows rough dollars for a Light / Typical / Heavy run for each model in `prices.json`.
Prices there are marked *verify*: check OpenAI's pricing page.

## Run
```
uv run python prompt_router.py examples/water-tracker.md
```
or point it at your own brief: `uv run python prompt_router.py docs/my_brief.md`.

Watch for:
- `[route] ...` which agent the Router chose and why
- `[model] asking ...` a call is in flight (long answers take a minute or more)
- `TOKENS AND COST` at the end, and `usage.json` in the run folder
- `[stop] Spending guard` the run hit its cost or token limit; finished work is still saved

## Where things go
```
prompts/    YOUR team's 8-section prompts (empty in the template repo)
examples/   a sample brief
docs/       the team project guide, workbook and templates
output/     run results (git-ignored)
```

## Settings (`.env`)
`MODEL`, `MAX_COST_USD` (default 2.00), `MAX_RUN_TOKENS` (default 1,000,000), `MAX_STEPS`,
`INPUT_TOKEN_BUDGET`, `REPLY_TOKENS`. See `.env.example`.

## Honest limits
The output is a **first draft** generated by a model. Your team must read it, test it, and fix it.
A run that "finishes" has not proven the app works.
